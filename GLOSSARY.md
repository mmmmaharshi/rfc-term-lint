# RFC Term Lint

A checker that grades research-paper wording against RFC requirement language.

## Language

**Plug-and-play**:
A user needs nothing beyond their MCP client: no Python, no clone, no installs.
_Avoid_: one-liner, zero-config

**Hosted server**:
The checker running on our server at a public URL, instead of a process on the user's machine.
_Avoid_: cloud version, remote
