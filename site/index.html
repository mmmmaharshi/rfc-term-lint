rfc-term-lint

Lints research-paper wording against BCP 14 (RFC 2119 + RFC 8174). Flags normative keywords, ambiguous lowercase usage, and suggests precise rewrites.

Use the hosted server

No install. Point your MCP client at the public URL:

{ "mcpServers": { "rfc-term-lint": { "url": "https://<host>/mcp" } } }

Tools

  • search_rfc_term — meaning of a MUST/SHOULD/MAY keyword
  • evaluate_text — flags normative hits + ambiguous lowercase
  • suggest_fix — rewrite suggestions for one paragraph

Self-host

docker build -t rfc-term-lint .
docker run -p 8000:8000 rfc-term-lint
